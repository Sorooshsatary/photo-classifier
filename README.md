# مسابقه خرید و فروش عکس

وب‌اپ مسابقه برای خرید و فروش عکس‌های شماره‌دار، مدیریت دارایی هر گروه و
آموزش مدل دسته‌بند روی عکس‌های خریده‌شده. **بدون گوگل‌شیت** — همه‌چیز از صفر
داخل خود سایت ساخته و خوانده می‌شود و مرجع داده **دیتابیس SQLite**
(`data/competition.db`) است.

مدل یک CNN کوچک PyTorch (`SmallCNN`) است که از صفر ترین می‌شود؛ ورودی
`128×128` و خروجی یکی از ۳ دسته است. مدل سراسری روی همه عکس‌های خریده‌شده
(به‌علاوه عکس‌های دستی تب آموزش) آموزش می‌بیند و هر گروه هم می‌تواند مدل
خودش را فقط با عکس‌هایی که خریده آموزش بدهد.

## پیش‌نیاز

- Python 3.11+ (محلی)
- یا Docker

## اجرا با Docker (پیشنهادی)

از پوشهٔ پروژه:

```bash
docker compose up --build
```

بعد مرورگر را باز کن:

http://127.0.0.1:7860

توقف:

```bash
docker compose down
```

## اجرای محلی بدون Docker

```bash
python -m pip install torch torchvision
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 7860
```

## جریان مسابقه

### ۱) عکس‌ها را در پوشه‌ها بگذار

- `all-photo/` — همه عکس‌های قابل خرید، با شماره در اسم فایل:
  `1.jpg`، `12.jpg` یا `photo-12.jpg` (اولین عدد اسم فایل شماره عکس است).
  سایت با دکمه «اسکن دوباره all-photo» پوشه را می‌خواند.
- `test/` — عکس‌های تست. سیستم خودش از پوشه می‌خواند؛ لازم نیست دستی
  آپلود کنی. اگر عکس تست داخل زیرپوشه‌ای به اسم یکی از دسته‌ها باشد
  (مثلاً `test/class_0/101.jpg`)، دقت تست هم حساب می‌شود.

### ۲) گروه‌ها

گروه‌ها همان حساب‌های `boy-1` تا `boy-20` و `girl-1` تا `girl-20`
(از `passwords.xlsx`) هستند و با اولین اجرای سرور در دیتابیس ساخته می‌شوند؛
ادمین می‌تواند از API گروه سفارشی هم بسازد. سرمایه شروع پیش‌فرض هر گروه
**۱۰۰۰** است (از تب مسابقه قابل تغییر است؛ فقط روی گروه‌های تازه‌ساخته اثر
می‌گذارد).

### ۳) ثبت خرید

از تب **مسابقه**: گروه را انتخاب کن، شماره عکس‌ها را بنویس (تکی یا بازه،
مثلاً `5, 12-15`)، دسته عکس‌ها را برای آموزش مدل گروه انتخاب کن و
**ثبت خرید** را بزن. قیمت پیش‌فرض هر عکس **۱۰۰** است؛ می‌توانی موقع خرید
قیمت دیگری بدهی یا قیمت یک عکس را جداگانه عوض کنی.

موقع ثبت خرید، در یک تراکنش دیتابیس چک می‌شود:
عکس در `all-photo` هست، قبلاً فروخته نشده، و پول گروه کافی است.
اگر یکی از عکس‌ها نشد، هیچ‌کدام خریده نمی‌شود. عکس خریده‌شده به دیتاست
آموزشی آن گروه (در دسته انتخاب‌شده) و به دیتاست سراسری کپی می‌شود و
ردیف خرید در دفتر ثبت می‌شود.

### ۴) فروش

**فروش برگشتی به بانک** با نرخ پیش‌فرض **۸۰٪** قیمت خرید انجام می‌شود؛
عکس دوباره آزاد می‌شود و از دیتاست گروه حذف می‌شود.

### ۵) دارایی هر گروه

برای هر گروه: موجودی نقد، عکس‌های خریده‌شده، کل خرید، ارزش دارایی
(جمع قیمت خرید عکس‌ها)، **ارزش خالص = نقد + ارزش دارایی**، تاریخچه کامل
خرید و فروش (دفتر)، و بهترین دقت تست مدل گروه. جدول امتیاز گروه‌ها را
بر اساس ارزش خالص مرتب می‌کند. خروجی اکسل (`گروه‌ها`، `دارایی‌ها`،
`دفتر خرید و فروش`) از تب مسابقه قابل دانلود است.

### ۶) آموزش و تست

- **مدل سراسری:** تب آموزش مدل — روی همه عکس‌های خریده‌شده + عکس‌های دستی.
- **مدل هر گروه:** از تب مسابقه، گروه را انتخاب کن و «آموزش مدل گروه»
  را بزن (هر دسته حداقل ۲ عکس خریده‌شده لازم دارد).
- **تست از پوشه:** از تب مسابقه، گروه (یا مدل سراسری) را انتخاب کن و
  «تست پوشه test» را بزن؛ برای هر عکس شماره، برچسب و درصد اطمینان می‌آید
  و نتیجه در دیتابیس ثبت می‌شود.
- تب **تست و برچسب** قدیمی هم هست: عکس تست را دستی وارد کن و برچسب بگیر.

## API مسابقه

- `GET /api/competition/state` وضعیت مسابقه و تنظیمات
- `POST /api/competition/rescan` اسکن دوباره `all-photo`
- `GET /api/competition/photos` لیست عکس‌ها با وضعیت و مالک
- `GET /api/competition/photos/{number}/image` عکس شماره‌دار
- `GET /api/competition/groups` جدول امتیاز گروه‌ها
- `GET /api/competition/groups/{id}` دارایی و دفتر یک گروه
- `POST /api/competition/buy` ثبت خرید (`group_id`, `numbers`, `class_index`, `price?`)
- `POST /api/competition/sell` فروش برگشتی (`group_id`, `numbers`)
- `POST /api/competition/settings` تنظیم سرمایه شروع، قیمت پیش‌فرض، نرخ فروش
- `POST /api/competition/train/{group_id}` آموزش مدل گروه
- `POST /api/competition/test-folder` تست پوشه `test` با مدل گروه یا سراسری
- `GET /api/competition/export.xlsx` خروجی اکسل گروه‌ها، دارایی‌ها و دفتر

## API قبلی (آموزش دستی)

- `GET /api/state` وضعیت دسته‌ها و آموزش
- `POST /api/classes` اسامی سه دسته (JSON array)
- `POST /api/upload/{0|1|2}` آپلود گروهی عکس برای یک دسته
- `POST /api/train` شروع آموزش سراسری (`epochs`, `batch_size`)
- `POST /api/predict` برچسب‌گذاری گروهی فایل‌های تست

## نکات

- فرمت‌های مجاز: `jpg`, `jpeg`, `png`, `webp`, `bmp`, `gif`
- اگر دقت بد بود، عکس بیشتر بگذار یا دور آموزش را بالا ببر.
- GPU لازم نیست؛ روی CPU هم کار می‌کند (کندتر).
- دیتابیس، عکس‌ها و مدل‌ها روی دیسک می‌مانند (در Docker با volume).
