# استودیوی دسته‌بندی عکس

وب‌اپ برای آموزش یک مدل سه‌کلاسه روی عکس‌های خودت، بعد برچسب‌گذاری گروهی دادهٔ تست.

مدل ازپیش‌آموزش‌دیده نیست. یک CNN کوچک PyTorch (`SmallCNN`) است که روی عکس‌هایی که وارد می‌کنی از صفر ترین می‌شود. ورودی `128×128` است و خروجی یکی از ۳ دسته.

## پیش‌نیاز

- Python 3.11+ (محلی)
- یا Docker

## اجرا با Docker (پیشنهادی)

از پوشهٔ پروژه:

```bash
docker compose up --build
```

بعد مرورگر را باز کن:

http://127.0.0.1:7860

عکس‌های آموزش در `dataset/` و وزن مدل در `models/` روی سیستم خودت ذخیره می‌شوند (volume).

توقف:

```bash
docker compose down
```

فقط با Dockerfile:

```bash
docker build -t judg .
docker run --rm -p 7860:7860 -v "%cd%/dataset:/app/dataset" -v "%cd%/models:/app/models" judg
```

روی لینوکس/مک به‌جای `%cd%` از `$(pwd)` استفاده کن.

## اجرای محلی بدون Docker

```bash
python -m pip install torch torchvision
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 7860
```

برای رابط دسکتاپ اختیاری (`app.py`) علاوه بر بالا `customtkinter` را هم نصب کن. در ویندوز می‌توانی `run.bat` را هم بزنی.

## راهنمای استفاده

### ۱) آموزش

1. تب **آموزش مدل** را باز کن.
2. اسم سه دسته را بنویس (مثلاً سگ / گربه / پرنده).
3. برای هر دسته عکس وارد کن:
   - چند فایل با هم
   - کل پوشه
   - یا Drag & Drop (پوشه هم قبول می‌شود)
4. هر دسته حداقل **۲ عکس** لازم دارد. هرچه بیشتر و متنوع‌تر، بهتر.
5. تعداد دور آموزش و اندازهٔ بچ را اگر خواستی عوض کن.
6. **شروع آموزش** را بزن و صبر کن تا تمام شود. مدل در `models/image_classifier.pt` ذخیره می‌شود.

### ۲) تست و برچسب

1. تب **تست و برچسب**
2. عکس‌ها یا پوشهٔ تست را گروهی وارد کن (این‌ها وارد دادهٔ آموزش نمی‌شوند).
3. **برچسب بزن** — برای هر فایل لیبل و درصد اطمینان می‌آید.
4. در صورت نیاز **خروجی CSV** بگیر.

### نکات

- فرمت‌های مجاز: `jpg`, `jpeg`, `png`, `webp`, `bmp`, `gif`
- اگر دقت بد بود، عکس بیشتر بگذار یا دور آموزش را بالا ببر.
- GPU لازم نیست؛ روی CPU هم کار می‌کند (کندتر).

## ساختار پروژه

| فایل | نقش |
| --- | --- |
| `server.py` | API و سرو کردن رابط وب |
| `static/` | رابط گرافیکی مرورگر |
| `model_engine.py` | معماری CNN، آموزش، پیش‌بینی |
| `dataset/class_0..2` | عکس‌های هر دسته |
| `models/` | وزن ذخیره‌شدهٔ مدل |
| `app.py` | رابط دسکتاپ قدیمی (اختیاری) |

## API

- `GET /api/state` وضعیت دسته‌ها و آموزش
- `POST /api/classes` اسامی سه دسته (JSON array)
- `POST /api/upload/{0|1|2}` آپلود گروهی عکس برای یک دسته
- `POST /api/train` شروع آموزش (`epochs`, `batch_size`)
- `POST /api/predict` برچسب‌گذاری گروهی فایل‌های تست
